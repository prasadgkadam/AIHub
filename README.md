# AIHub - AI Centralized Platform

## Overview

AIHub is a centralized platform that integrates multiple AI tools and services into a single web application. The platform provides users with easy access to various AI-powered functionalities through a unified and user-friendly interface. It eliminates the need to visit multiple websites by bringing different AI services together in one place.

## Features

* User Registration and Login System
* Secure Authentication and Session Management
* Dashboard for Managing AI Tools
* Profile Management
* OTP-Based Verification
* Password Reset Functionality
* Subscription and Pricing Management
* Rate Limiting for Security
* Responsive User Interface
* Admin and User Management

## System Architecture

1. User accesses the AIHub platform.
2. Authentication verifies user credentials.
3. Users browse and access available AI tools.
4. Requests are processed through the backend.
5. Results are displayed through the web interface.
6. User activities and subscriptions are managed securely.

## Installation

### Prerequisites

* PHP 8.0 or higher
* MySQL Server
* Apache/XAMPP/WAMP

### Steps

1. Clone the repository:

```bash
git clone https://github.com/your-username/AIHub.git
```

2. Move the project to your web server directory.

3. Create a MySQL database.

4. Import the provided SQL database file.

5. Configure database credentials in the project configuration file.

6. Start Apache and MySQL services.

7. Open the application in your browser:

```text
http://localhost/aihub2/
```
